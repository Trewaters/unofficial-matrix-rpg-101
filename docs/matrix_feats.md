Matrix Feat Skills
Matrix Feats are special skills that work differently than other skills. Matrix Feats are one of the few skills that only work in the Matrix simulation. They are useless outside the Matrix simulation. Matrix Feats are the character’s ways of Bending or Breaking Matrix laws of physics. Matrix Feats cannot be downloaded into your brain like other skills. Nor can Matrix Feats be programmed. To any computer Matrix Feats should not work. Matrix Feats are a series of errors and nonsense loops. Matrix Feats must be acquired by paying experience to learn and develop that specific Matrix Feat skill. They don’t specialize like other skills. When a character reaches Master Level in a Matrix Feat they are not allowed to pick a specialization for a +1 die.

Matrix Feats are not limited to the list in this book. If a player and GM can agree on rule bending and breaking descriptions then they can make another Matrix Feat. Matrix Feats can only be learned, they can’t be programmed. Sometimes a character doesn’t have the experience to buy a Matrix Feat but they want to use the power on the fly. GM’s can allow characters to only roll their CyberZen versus a threshold set by the GM. If they make the threshold then the GM grants them a very limited Matrix Feat that works to get the job done, for now.

Matrix Feats have two descriptions. The rule bending description is what characters use without the Gift. The rule bending description is a weaker version of the Matrix Feat. They are still superpowers but they aren’t god like with the ability to break the rules of the Matrix, yet. Once the player upgrades their CyberZen and buys the Gift they have access to both the descriptions. The rule breaking description is a more powerful version of the Matrix Feat that usually breaks the rules of the Matrix. 

Matrix Feat “Acute Hearing” - [CyberZen]
Rule Bender Feat: The ability to hear sounds that would normally be too low or too far off to hear with normal hearing.
Rule Breaker Feat: Character can hear any frequency even those that are normally inaudible to human ears.

Matrix Feat “Atmospheric Adaptation” - [CyberZen]
Rule Bender Feat: Character can breathe noxious gases without any adverse effects. Even though characters can inhale noxious gases they are unable to breathe underwater.
Rule Breaker Feat: Character can breathe water, noxious fumes/gases, or go without oxygen completely.

Matrix Feat “Blindness” - [CyberZen]
Rule Bender Feat: The characters must be able to touch their target. With a simple touch the character can make a RSI blind. They can affect a number of targets equal to their Matrix feat rating.
Rule Breaker Feat: Character can make a redpill RSI blind while they are plugged into the Matrix. The effect last as long as the targets stay in the Matrix.

Matrix Feat “Change Material” - [CyberZen]
Rule Bender Feat: The character has the ability to change the weight, size, and the color of an item temporarily. The item retains its shape and possibly its original function depending on how it is altered (GM's discretion). The character can only affect one item at a time. The objects that are affected must be smaller than the character.
Rule Breaker Feat: The character has the ability to alter an object's molecular structure in the Matrix, i.e.,changing a gun to butter, concrete to water, water to wine, etc. The items retains its shape and possibly function depending on how it is altered (GM Discretion). A single object of any size can be changed in this way.

Matrix Feat “Control Animal(s)” - [CyberZen]
Rule Bender Feat: The character has the ability to lock gazes with an animal and make that particular animal follow his commands.
Rule Breaker Feat: The character can control more than one animal at a time. Characters are only able to control as many animals as their Matrix feat rating.

Matrix Feat “Control Gravity” - [CyberZen]
Rule Bender Feat: Character can control how gravity works by increasing or decreasing it on one person or object. They have to touch the object.
Rule Breaker Feat: Character can control gravity in an area that they can see. They can control how gravity works in an area around the character equal to their Matrix feat rating in meters.

Matrix Feat “Control Plant(s)” - [CyberZen]
Rule Bender Feat: Character can touch a plant and make it grow, and grow in certain direction. To imagine this feat think of the plant reaching towards the sun, but the character can make that happen rapidly.
Rule Breaker Feat: Character can make multiple plants grow or wither at will. The character must be in close proximity of the plants. GM discretion as to whether the character could affect an entire acre or farm of crops.

Matrix Feat “Control Weather” - [CyberZen]
Rule Bender Feat: Make a rain storm on a sunny day. The more abnormal or extreme the weather change the more difficult the task roll. Creating clouds in an office building is very difficult.
Rule Breaker Feat: Without changing the entire weather pattern the person can call lightning to strike in an spot of their choosing. The character could call a tornado spiral on a calm day with no other winds around at the same time.

Matrix Feat “Create Simple Objects” - [CyberZen]
Rule Bender Feat: The character can restore simple objects that have been destroyed. For example the character can restore a burnt candle to its original state. They must touch the item.
Rule Breaker Feat: The character has the ability to make small simple objects from nothing. Simple objects don't have any moving parts. The character must touch the item being made.

Matrix Feat “Disguise” - [CyberZen]
Rule Bender Feat: A player can disguise herself to agents and other people within the Matrix. RSI's don’t see the character as she is, but rather as she would like to be seen.
Rule Breaker Feat: Player can change their height and weight. It is even possible to alter appendages like growing a lost appendage. Mimic someone specifically down to the DNA. Indiscernible from the original. Characters must stay human.

Matrix Feat “Dodging Bullets” - [CyberZen]
Rule Bender Feat: Character has an uncanny ability to dodge non-ballistic speed objects. Character can easily dodge bows and arrows.
Rule Breaker Feat: The character can dodge ballistics and projectiles in the Matrix. When a character uses dodge they cannot perform any other actions that turn.

Matrix Feat “Eagle Eyes” - [CyberZen]
Rule Bender Feat: Character can see long distances as though they were closer. It would be possible to read a newspaper article that is a block away as though they were holding the newspaper in their own hands. This Matrix feat gives the user extreme tunnel vision. While using this ability they have difficulty focusing on things closer than their target range.
Rule Breaker Feat: Character's eyes can vary their magnifaction from normal to the power of an electron microscope. They always have the tunnel vision when using this feat.

Matrix Feat “Enhanced Smell” - [CyberZen]
Rule Bender Feat: Character smells scents like a blood hound. They can use this abilit to track a person or object by its scent.
Rule Breaker Feat: A character can use smell to identify anyone they have smelled before, even if the person is trying to disguise themself as someone else. The character is so sensitive to smells they can pick up pheromones similar to how ants follow each other.

Matrix Feat “Firestarter” - [CyberZen]
Rule Bender Feat: Character is able to increase or decrease the intensity of fire that is already burning. Cannot create flame from nothing.
Rule Breaker Feat: Character can create fire from nothing. It is easier if they have something to set on fire.

Matrix Feat “Flight” - [CyberZen]
Rule Bender Feat: Character glide on air currents without the aid of wings. They could take a running jump and use that to start their gliding. Gliders are not propelled so they don’t move fast unless they are diving, and they slow down when climbing. The character can also turn off this Matrix Feat allowing them to fall to the ground normally.
Rule Breaker Feat: The character can fly like superman.

Matrix Feat “Forcefield” - [CyberZen]
Rule Bender Feat: The character can create a forcefield around their body that can repel objects, gases, or forces from touching the character. This field is on the surface of the characters body.
Rule Breaker Feat: Extend this forcefield to others, or around a certain area. They only control one forcefield. If they are using the forcefield to protect someone else they are not protected themselves.

Matrix Feat “Grow Claws” - [CyberZen]
Rule Bender Feat: Alter nails and teeth so they have a razor sharp edge. They can also make them hard as diamonds.
Rule Breaker Feat: Grow fingernails and toenails longer and stronger like cat claws. Character could even make bone poke through skin in  desired areas.

Matrix Feat “Increased Attribute” - [CyberZen]
Rule Bender Feat: Make a task roll. For each success increase that attribute's dice pool by one die for the remainder of the scene. This cannot increase the Cyberzen attribute. The amount of points that a character can adjust is equal to Matrix Feat rating. But that can be added up from multiple Attributes. For example a rating 3 Matrix Feat could adjust Strength +2 and Focus + 1. If they want to increase another attribute then they will have to give up one of the current adjustments they already have.
Rule Breaker Feat: Increase Cyberzen. No limit to the amount of Attribute points the character can increase.

Matrix Feat “Increased Skill” - [CyberZen]
Rule Bender Feat: Make a task roll. For each success increase that skill's dice pool by one die for the remainder of the scene. The amount of points that can be adjusted by this Matrix Feat is equal to its rating. Similar to Increased Attribute.
Rule Breaker Feat: No limit to the amount of Skill points that the character can increase.

Matrix Feat “Invisibilty” - [CyberZen]
Rule Bender Feat: The character becomes harder for people to see. The character does not become translucent, but they can only be seen if someone were starring directly at them and focusing.
Rule Breaker Feat: A character can become completely translucent, light travels  through them. Clothes and other items the character is wearing are unaffected by this feat.

Matrix Feat “Jump” - [CyberZen]
Rule Bender Feat: Soften a deadly fall of twenty stories, or jump across extreme distances as though they were much smaller. You could jump across the Grand Canyon with this feat.
Rule Breaker Feat: Jump gets very similar to fly once a character has the gift. They can jump as far as they want. The difference from flying is they can’t do the superman thing. The character can jump for miles as long as they are moving up and down not side to side.

Matrix Feat “Mimic” - [CyberZen]
Rule Bender Feat: Character can turn body into an element that they have come in contact with. The body can move like normal but it has all the other characteristics of the element they copied.
Rule Breaker Feat: By touching an object, person, animal, or bug the character can become a copy of that thing down to the smallest detail. The character does not have to stay human. They could mimic a monkey but they must touch it.

Matrix Feat “Mind Control” - [CyberZen]
Rule Bender Feat: Character can plant small one word suggestions or ideas into a RSI’s mind. Upon a successful roll the bluepill RSI will carry out that suggestion until its completion. The character can leave the Matrix and that character will attempt to complete the suggestion. The RSI will only follow suggestions that don’t hurt them. The person cannot be controlled to kill themselves or jump in front of an oncoming bus.
Rule Breaker Feat: The character can possess bluepill RSIs. The character has a psychic link with the RSI and can tell them to do what they want. They don’t see what the possessed RSI sees but they know what they know. The character also has the ability to manipulate memories.

Matrix Feat “Negate Matrix Feats” - [CyberZen]
Rule Bender Feat: Character can temporarily negate the Matrix Feat ability and effects of other RSI’s or programs.
Rule Breaker Feat: The character can permanently negate the Matrix Feat ability and effects of other RSI’s or programs.

Matrix Feat “Night Vision” - [CyberZen]
Rule Bender Feat: Characters determine how night vision works for them. Either they use Sonar, low light, or heat (infra-red).
Rule Breaker Feat: Character doesn’t need to see. They are completely aware of what is around them as though it were daylight. The character knows what is being illuminated by their Matrix Feat and they can turn the feat off if they want.

Matrix Feat “Pass Through Objects” - [CyberZen]
Rule Bender Feat: Character can pass through thick liquids and objects as though they were made of air. For example using this gift in water would allow the character to run and move as though they were on land.
Rule Breaker Feat: The character can walk through walls and pass through solid objects as though they were made of air.

Matrix Feat “Prehensile” - [CyberZen]
Rule Bender Feat: Character can use their tongue, feet and ears to grab things as though they were using their hands. The character could use their feet to fire a hand gun without any difficulty.
Rule Breaker Feat: Character can grow extra prehensile appendages they can use just like hands. They could even grow an extra arm.

Matrix Feat “Psychometry” - [CyberZen]
Rule Bender Feat: A character can learn about the past of an object, place, or person by touching it.
Rule Breaker Feat: A character can learn about the future of an object, place, or person by touching it.

Matrix Feat “Shapeshifting” - [CyberZen]
Rule Bender Feat: A character can turn into an animal of their choice if they see it while they are shifting.
Rule Breaker Feat: Character can shapeshift into any animal it has ever seen before, even without the animal present while the character is shifting.

Matrix Feat “Sonic Blast” - [CyberZen]
Rule Bender Feat: Create a sonic blast that can shatter brittle materials like glass. It can also damage human eardrums or be used to stun an opponent.
Rule Breaker Feat: Character can use their sonic blast to knock people over and hit things with force. A character could use the sonic blast to lift them up in the air or propel them along in the air.

Matrix Feat “Spatial Manipulation (Spatiokinesis)” - [CyberZen]
Rule Bender Feat: Character can design an area in the matrix that allows them to control reality. This area does not change until it is destroyed or reformatted.
Rule Breaker Feat: Character can manipulate the spatial reality of their immediate area, wherever that is. Users can warp, bend, flip, crush, control and otherwise manipulate all physical aspects space within area of ones choosing. It allows only the ability to manipulate an area, not to defy its laws, so gravity, friction, and many other rules will still usually apply. However, it is possible for users of this power to give the illusion that they are manipulating gravity by Floortilting or by manipulating spatial pressure, such as decreasing the spatial size of a basketball without altering its structure. Users cannot affect people or objects, but they could fold space onto itself making the same object take up two different places. Rule Benders are limited to a specific location, Rule Breakers are restricted only by their imagination. 

Matrix Feat “Telekinesis” - [CyberZen]
Rule Bender Feat: Character has the ability to lift objects up to their weight if they focus on it. They must see the object.
Rule Breaker Feat: Character has the ability to lift objects that weigh more than them with their minds, but they must be able to see it.

Matrix Feat “Telepathy” - [CyberZen]
Rule Bender Feat: Character can read surface thoughts of other RSI’s. If the person actively resist having their mind read it makes the roll more difficult for the players. People can notice when someone is reading their thoughts. It feels like someone is holding your head. It is not painful but noticeable. This is limited to one RSI at a time. (difference between Telepathy and Mind Control  is Mind Control allows the RSI to implant thoughts. Telepathy only allows a player to read thoughts)
Rule Breaker Feat: Characters can read any thoughts that the RSIs have. Even the person tries to hide a thought or memory they will be able unearth it with a little time and focus. This is limited to as many RSIs as their Matrix Feat.

Matrix Feat “Teleportation” - [CyberZen]
Rule Bender Feat: A character can teleport very limited distances. Basically if they can see it they can teleport there.
Rule Breaker Feat: Can teleport to any destination in the Matrix. Period.

Matrix Feat “Time Slow” - [CyberZen]
Rule Bender Feat: For limited periods the character can slow down one object or person in the area. Usually when the character is in combat or in danger they pick one object or person to slow down. The object is slowed down for everyone not just to the RSI with the Matrix Feat.
Rule Breaker Feat: The character can slow down the actions of everyone else around them, making the player appear to move faster than everyone else. This is limited to an amount of objects not to exceed the Matrix Feat rating.

Matrix Feat “True Sight” - [CyberZen]
Rule Bender Feat: The character can see random snippets of code. It is up to the GM as to what the character sees when they use this ability. It should be small bits of information.
Rule Breaker Feat: The character can see all of the simulacrum as Matrix code from within the Matrix.

Matrix Feat “Truth Sayer” - [CyberZen]
Rule Bender Feat: The character can tell when someone is lying about anything, or when that person thinks they are lying about something.
Rule Breaker Feat: The character can force a RSI to only tell the truth as far as they know. They don’t feel compelled to talk, but anything they say is the truth and they don’t know why.

Matrix Feat “Wall Crawling” - [CyberZen]
Rule Bender Feat: The character can cling to walls with hands and/or feet like a spider or climbing insect. If the surface is smooth or wet then crawling is more difficult. Much like fi the person was walking on ice. It is difficult to be completely upside down, the character must concentrate to be upside down.
Rule Breaker Feat: The character can cling to ceilings and walls made of any material with any type of surface, slippery or not.

Matrix Feat “X-Ray Vision” - [CyberZen]
Rule Bender Feat: Not literally using X-Rays to see through objects. Character can see through thin walls and clothes as though they weren’t there.
Rule Breaker Feat: Character can see through lead and thick concrete as though it were not there.

Matrix Feat “Heal” - [CyberZen]
Rule Bender Feat: Character can roll Endurance to reduce damage up to their Cyberzen rating, in one day.
Rule Breaker Feat: Character can lay hands on a character and allow them to roll their Endurance score to reduce damage even if they have already rolled once this 24 hour period.
