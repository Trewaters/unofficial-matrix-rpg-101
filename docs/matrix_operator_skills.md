Operator Skills
Skills used by an Operator to get things done. They are an important part of the crew. Their skill set is very specific.

Programming [Focus]- Being able to read the Matrix code. Use Programming to create simulacra equipment for the Matrix, etc. When a party or person is in the loading area before they broadcast, they have all the equipment that they can take. 
Hacks that help RSIs get things done in the Matrix. RSIs need an Operator, who is like a copilot, and their copilot needs to know some Hacks to help them get around in the system. Hacks help the Operator watch a character’s back. Programming Hacks help an Operator know enough programming to see the construct for what it is. Operators have a better view of what is happening inside the Matrix than the players do.
The moment before an Operator can jack people into the Matrix, he must make a task roll to see how many hardlines he can secure for his team to go into the Matrix. If the Operator makes the task threshold they get one secure hardline. For every success rolled above the Task Threshold they secure an additional hardline for the group. These hardlines are secure connections that the operator uses to broadcast RSIs in and out of the Matrix. An Operator can check if her hardlines have been cut. An Operator has a limited number of spaces for that particular broadcast. He can have all his hardlines secure or, if they have been cut or damaged for some reason, he can secure another until his maximum amount of secure hardlines have been filled. [Example: An Operator makes a task roll to see how many hardlines he can secure for the connection, let’s say it is 5. These are 5 secure locations that he can use to bring RSI in and out of the Matrix. If a hardline is cut, he can secure another so that he is back to the 5 hardlines he is allowed to maintain.] It is suicide to use a non-secure hardline; an unsecured hardline could have Agents at the other end of the line.
Operators also need to be aware of their hardline’s bandwidth. It is more difficult for an Operator to secure hardlines with large bandwidths. The more network traffic the higher the bandwidth. High bandwidth hardlines increase the Operator’s difficulty level for securing that hardline. So if a crew is trying to broadcast a Navy ship it would be next to impossible because the bandwidth for that would be ridiculous. It would be better to build a Navy Ship in the Matrix and use that one.
The Operator makes the task roll to assist the RSIs in the Matrix. The Operator can add dice to the RSI’s dice pool. This helps represent the advance knowledge that the Operator is sharing with the players. The Operator also helps with lots of roleplay knowledge. The Operator can see what the characters can’t. For example an Operator can see through walls. For every success on the Operator’s task roll, the RSI gets additional dice added to their dice pool. This affect lasts as long as the Operator’s information is still helpful. That is left up to the GM’s discretion.

Matrix Power Plant Hardware [Focus]- Understanding the actual hardware and tech that makes up any construct based technology.
