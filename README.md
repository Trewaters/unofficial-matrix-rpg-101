# The Unofficial Matrix RPG Character Sheet

Local-first web app for creating and saving player character sheets for The Unofficial Matrix RPG.

## Features

- Matrix-themed landing page with Learn and Play paths
- Player character sheet with identity, attributes, damage, skills, Matrix feats, equipment, and notes
- Browser local storage persistence for future sessions on the same device
- JSON export and import for backups or moving sheets between devices
- Ethereum NFT viewing placeholder fields reserved for a later read-only wallet integration

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
